# Gold Snake 3D

Snake autonome avec un rendu 3D simulé (lumières, ombres, relief et reflets), en HTML/CSS/JavaScript sans dépendances.

## Jouer

Ouvrir `index.html` dans le navigateur. Clavier : flèches ou ZQSD / WASD ; téléphone : glissement sur le plateau ou commandes tactiles ; espace : pause. Trois vitesses et record local.

Ce jeu est publié sur Cloudflare Workers, et peut aussi être hébergé sur GitHub Pages.
