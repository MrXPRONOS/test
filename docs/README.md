# RETRO FOOT 3D — CR GAME

Jeu HTML5 (V1.2 par défaut), sans dépendance externe. Version V1.1 dans /v1.1/ et version V1.2 dans /v1.2/.

## GitHub Pages
Sur un dépôt GitHub dédié ou sur un dépôt existant, placer ce dossier à la racine sous docs/, puis choisir Settings > Pages > Deploy from a branch > main > /docs. Ne pas remplacer le index.html d'une autre application.

La branche retro-foot-v1.2-pages est préparée dans MrXPRONOS/test sans modifier main. Elle n'est **pas** automatiquement publiée sur GitHub Pages.
