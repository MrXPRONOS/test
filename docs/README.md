# RETRO FOOT 3D — CR GAME

Jeu HTML5 V1.2 (par défaut) + V1.1, entièrement statique.

## Publication via GitHub Pages depuis la branche préparée

Dépôt : `MrXPRONOS/test`  
Branche : `retro-foot-v1.2-pages`  
Répertoire à publier : `/docs`

Ouvrir **Settings → Pages** dans GitHub, choisir **Build and deployment → Source : Deploy from a branch**, puis **Branch : retro-foot-v1.2-pages** et **Folder : /docs**, et sauvegarder.

Après publication, URL attendue : https://mrxpronos.github.io/test/ (à vérifier dans GitHub Pages avant de communiquer comme lien actif).

Le jeu n'a pas été intégré dans `main` et GW Suivi n'a pas été modifié. Cette branche sert de publication isolée dans le dépôt existant, en attendant un dépôt dédié `retro-foot` si souhaité.

## Commandes

PC : flèches/WASD, J pour passer, K pour tirer, X pour feinter/tacler, Maj pour sprinter, Espace pour changer de joueur. Mobile : joystick et boutons à l'écran.

## PWA

Manifest, icône SVG et cache hors ligne inclus. Nécessite HTTPS pour l'installation et le service worker.
